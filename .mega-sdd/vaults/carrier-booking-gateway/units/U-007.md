# Unit U-007 — Build the carrier-core HttpClient (timeout, retry/backoff, circuit breaker, message log hook)

## Goal

Implement the `HttpClient` factory: per-carrier base URL, request timeout, retry with exponential backoff + jitter on retryable failures, a per-carrier circuit breaker, and a hook that records every exchange for the `carrier_messages` log.

## Context (read first)

Per spec §8, every adapter calls the carrier through this one client so retry, breaking, and audit logging are uniform. The client is transport plumbing only — auth is layered on in U-008, and the actual `carrier_messages` insert is done by the callback the domain layer passes in (U-013); this unit defines the hook signature and calls it with `{ carrierCode, direction, operation, httpStatus, requestBody, responseBody, latencyMs, errorText, correlationId }`, secrets already redacted by the caller-supplied redactor.

## Hard rules

- DO NOT import from apps/booking or packages/db in packages/carrier-core/src/http
- NEVER retry a VALIDATION or AUTH error; retry only failures the caller marks retryable
- NEVER pass unredacted auth headers or secret fields to the message-log hook (constitution B-003)

## Implementation steps

1. Write `retry.ts` with `withRetry(fn, { maxAttempts, baseDelayMs, factor, jitter })` that retries only when `fn`'s rejection carries `retryable: true`, applying exponential backoff with full jitter and surfacing the last error otherwise.
2. Write `circuitBreaker.ts` with a per-key breaker (`closed` → `open` after `failThreshold` consecutive failures, `half-open` single probe, back to `closed` on success), exposing `state(key)` for `/health`.
3. Write `client.ts` exporting `createHttpClient({ baseUrl, timeoutMs, failThreshold, authStrategy, onExchange, redact })` returning an object with `request(operation, path, init)` that applies auth, enforces the timeout (AbortController), runs through the breaker and `withRetry`, calls `onExchange` once per attempt, and returns a normalized `{ status, body }` or throws a classified error.
4. Write `client.test.ts` covering: a retryable 503 retried then succeeding; a 400 not retried; the breaker opening after N failures and rejecting fast; `onExchange` called with redacted bodies.
