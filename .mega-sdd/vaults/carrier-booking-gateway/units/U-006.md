# Unit U-006 — Define the CarrierAdapter interface, AdapterContext, and adapter registry type

## Goal

Declare the transport-agnostic `CarrierAdapter` interface, the injected `AdapterContext`, and the `AdapterRegistry` type keyed by carrier code.

## Context (read first)

Builds on U-005's types. Per spec §8 and decision D-004, an adapter exposes `createBooking` / `getBookingStatus` / `cancelBooking` / `getTracking` / `toCanonicalStatus` and an optional `handleWebhook?` (unused in v1), and it never touches the database. How an adapter fulfils a method — REST now, EDIFACT later — is its own concern. `AdapterContext` carries the bound HTTP client, resolved credential, a correlation-aware logger, and a clock; the domain layer builds one per call (U-013).

## Anchors

- packages/carrier-core/src/types.ts — AdapterResult, AdapterError, BookingAck, CancelAck, NormalizedEvent, CarrierCapabilities
- packages/carrier-core/src/status.ts — CanonicalBookingStatus (return type of toCanonicalStatus)

## Hard rules

- DO NOT import a concrete HTTP or DB module in packages/carrier-core/src/adapter.ts
- NEVER expose a CarrierAdapter method that accepts or returns a DB row type (constitution C-001)
- DO NOT implement handleWebhook in v1; it stays optional and unused (constitution D-004 scope)

## Implementation steps

1. Write `context.ts` defining `AdapterContext` with `http: HttpClient` (type imported from U-007's module path, declared here as an interface to avoid a cycle — U-007 implements it), `credential: ResolvedCredential`, `logger: Logger`, `clock: () => Date`; also define `ResolvedCredential` as the decrypted shape the store hands back.
2. Write `adapter.ts` defining `CarrierAdapter` with `readonly code`, `readonly transport: 'REST' | 'EDIFACT' | 'HYBRID'`, `readonly capabilities: CarrierCapabilities`, the four async methods returning `AdapterResult<...>`, the sync `toCanonicalStatus(carrierStatus: string): CanonicalBookingStatus`, and the optional `handleWebhook?`.
3. Define `AdapterRegistry = Map<string, CarrierAdapter>` and a `getAdapter(registry, code)` helper that throws a typed error when a code is missing or its carrier is disabled.
4. Add a compile-only test: a minimal in-file stub implementing `CarrierAdapter` must typecheck.

## Out of scope

- The real registry population with four adapters (U-024).
