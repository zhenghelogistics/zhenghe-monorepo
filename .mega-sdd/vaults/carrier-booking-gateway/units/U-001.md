# Unit U-001 — Scaffold the pnpm monorepo skeleton and CI

## Goal

Create the empty `zhenghe-monorepo` skeleton: pnpm workspaces, a shared TS/lint/format config package, a base tsconfig, `.env.example`, and a CI workflow that runs typecheck + lint + test.

## Context (read first)

This is the first unit of the build; nothing exists yet except the design spec and this vault. Per `vault.md ## Architecture` and the source spec §4, the repo is a pnpm-workspace monorepo with `apps/` and `packages/` folders, TypeScript from the first commit, and normal (non-serverless) tooling. The one user-visible outcome is that `pnpm install && pnpm -w run build && pnpm -w run typecheck && pnpm -w run test` all succeed on an otherwise empty scaffold. No application code, no database, no carrier logic here.

## Hard rules

- file:packages/config/*.js MUST follow kebab-case naming
- NEVER add a runtime dependency in this unit; only the shared dev toolchain (typescript, eslint, prettier, vitest) is in scope
- NEVER add a JavaScript source file to any package or app (constitution A-001)

## Implementation steps

1. Write `pnpm-workspace.yaml` declaring `apps/*` and `packages/*` as workspace globs, and a root `package.json` with workspace scripts (`build`, `typecheck`, `lint`, `test`) that fan out with `pnpm -r`.
2. Add `tsconfig.base.json` with strict settings (`strict`, `noUncheckedIndexedAccess`, `moduleResolution: bundler` or `node16`) that every package extends.
3. Create `packages/config` exporting a shared ESLint flat config and a Prettier config, plus a `tsconfig` preset; other packages depend on it by workspace name. Add `config.test.ts` — a vitest smoke asserting the exported ESLint config is a non-empty array and the tsconfig preset has `compilerOptions.strict === true`.
4. Write `.env.example` listing every key the spec §16 names (`DATABASE_URL`, `CARRIER_CRED_MASTER_KEY`, `POLL_INTERVAL_BOOKING_MIN`, `POLL_INTERVAL_TRACKING_MIN`, `HTTP_TIMEOUT_MS`, `CIRCUIT_FAIL_THRESHOLD`, `LOG_LEVEL`, and one `*_BASE_URL` per carrier) with placeholder values only.
5. Add `.github/workflows/ci.yml` that installs with pnpm and runs `typecheck`, `lint`, and `test`; leave a commented `services: postgres` block wired for the DB-backed tests that arrive in U-004/U-014/U-018.
